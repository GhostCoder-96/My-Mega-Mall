# My Mega Mall Inventory Management System

A Python-based desktop inventory management system developed for a ladies Indian suits business.  
This software was originally created as a freelance project to manage vendors, manufacturers, categories, products, and inventory records through a simple graphical interface.

---

## Features

- Vendor Management
- Manufacturer Management
- Category & Subcategory Management
- Product Management
- Inventory Tracking
- AYNP Product Code Generation
- CSV-Based Data Storage
- Product Size & Quantity Management
- Cost Price & Selling Price Handling
- Simple GUI using Tkinter

---

## Technologies Used

- Python
- Tkinter
- CSV
- OS Module

---

## Project Purpose

This project was developed for a local retail business to simplify inventory handling and product management for ladies ethnic wear products.

The software allows the business owner to:
- maintain product records
- manage stock entries
- organize categories
- track vendors and manufacturers
- store inventory data locally without requiring internet access

## How to Run

### 1. Install Python

Download Python from:

https://www.python.org/downloads/

---

### 2. Run the Application

Open terminal/cmd inside the project folder and run:

```bash
python "My Mega Mall.py"
```

---

## Data Storage

The application stores all records locally using CSV files.

If the CSV files do not exist, they are automatically created when the program runs.

---

## Notes

- This project uses Tkinter for the GUI.
- Data is stored locally and does not require a database.
- Designed specifically for offline inventory management.
- Originally developed as a freelance client project.
